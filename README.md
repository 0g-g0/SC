# Cybersecurity Study Coach — 53 open days

Run `npm install` followed by `npm run dev`, then open http://localhost:3000. Verify with `npm run build`.

The plan has no fixed start date or daily unlocks. All 53 days can be opened at any time. The dashboard points to the first incomplete day. Days 1–3 are dedicated exclusively to Satr and show only the official Satr site link. Then 25 topics follow, two days each, starting with Windows on day 4. Day 2 of each topic prompts review of resources in your Discord server.

On first visit, a welcome joke appears, then popup questions for name, language and daily study hours. Each day page and the dashboard contain a joke. Progress is stored in your browser; export it before switching devices. Progress from the previous 50-day plan is shifted three days ahead on load or import to preserve topic progress.

Topic pages have five targeted video searches, not verified individual videos, and five established learning destinations. Satr pages contain no other resources. Some inherited topic checklist items remain English-only.
